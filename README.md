# PRISMA Design System — @laban/ui

[![CI](https://github.com/laban/laban-ui/actions/workflows/ci.yml/badge.svg)](https://github.com/laban/laban-ui/actions)
[![License](https://img.shields.io/badge/license-Apache%202.0-blue.svg)](LICENSE)

Shared UI component library for the PRISMA ecosystem.

## Quick Start

```bash
npm install
npm run storybook
# Storybook at http://localhost:6006
```

## Components

- `colors.ts` — PRISMA color palette (Dark Mode, Lens Shutter, RIASEC)
- `animations.ts` — Framer Motion presets
- `prisma-font.css` — PRISMA SANS font
- `SplashScreen.jsx` — "Lăng kính Khai mở" animation

## Publishing

```bash
npm run build
npm publish --access public
```
